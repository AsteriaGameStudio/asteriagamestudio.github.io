# Asteria Game Studio

**Web y políticas de privacidad · Website and privacy policies**

## Español

Repositorio de la web pública de Asteria Game Studio, un proyecto independiente de videojuegos y aplicaciones.

Actualmente, la web aloja la [política de privacidad de SkullMerge](https://asteriagamestudio.github.io/#es), disponible en español e inglés.

### Proyectos del estudio

- **SkullMerge:** videojuego en proceso de acceso a producción de Google Play.
- **Viae:** aplicación educativa en desarrollo.
- **Entrenamiento y agenda:** ideas para futuras aplicaciones; todavía no están en desarrollo.

### Contenido del repositorio

- `index.html`: política de privacidad bilingüe de SkullMerge.
- `README.md`: presentación del repositorio y estado de los proyectos.

[Perfil de Asteria Game Studio](https://github.com/AsteriaGameStudio)

## English

Public website repository for Asteria Game Studio, an independent game and app development project.

The website currently hosts the [SkullMerge privacy policy](https://asteriagamestudio.github.io/#en), available in Spanish and English.

### Studio projects

- **SkullMerge:** a video game in the process of obtaining production access on Google Play.
- **Viae:** an educational app in development.
- **Training and planner apps:** ideas for future applications; development has not started.

### Repository contents

- `index.html`: bilingual SkullMerge privacy policy.
- `README.md`: repository introduction and project status.
